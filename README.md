# 💾 세이브 파일 공방 — 파이썬 파일 입출력

펫 「비트」 를 키우는데, **껐다 켜면 알로 돌아갑니다.**
학생이 저장 · 불러오기 · 일지 코드를 직접 짜면 **그 코드가 게임 안에서 진짜로 돌아가** 펫이 살아남습니다.

- 대상: 고등학교 「정보」 · 성취기준 `[12정03-05]` 표준입출력과 파일입출력을 활용한 프로그램을 작성한다.
- 범위: 교재 12장 B 파일 입출력 — `open` · `read` · `readline` · `readlines` · `write` · `close` ·
  `'r'` · `'w'` · `'a'` · `with` · `FileNotFoundError` · `\n` 과 `strip()`
- 분량: 1차시(50분) 기준, 카드 13장 (⭐ 10번은 빨리 끝낸 학생용)
- **설치도 인터넷도 필요 없습니다.** 파이썬이 브라우저 안에서 돌아갑니다(인터넷이 없으면 글꼴만 기본 글꼴로 바뀝니다).

## 여는 방법

| 방법 | 하는 일 |
|---|---|
| `dist/index.html` 더블클릭 | 그대로 열립니다. 학생에게 이 파일 하나를 나눠 줘도 됩니다. |
| 주소 끝에 `?demo` | 편집기마다 모범 답이 들어 있는 **선생님 시연 모드** |
| 오른쪽 위 🧹 | 그 브라우저의 기록을 모두 지우고 처음부터 (컴퓨터실 다음 반 시작 전) |

## 카드 13장

| # | 카드 | 배우는 것 |
|---|---|---|
| 0 | 🥚 알이 깨어났다 | 게임 속 펫은 변수 셋(name · level · hunger) |
| 1 | ⏻ 리셋의 충격 | 메모리(변수)는 꺼지면 사라지고, 디스크(파일)는 남는다 |
| 2 | 📝 첫 세이브 | 열기 → 쓰기 → 닫기 |
| 3 | 🐛 세이브 버그 둘 | `write( )` 는 글자만 받고(TypeError), 줄을 바꿔 주지 않는다(`\n`) |
| 4 | 📖 읽기 삼형제와 책갈피 | `read` · `readline` · `readlines` 와 읽는 자리 |
| 5 | 🔢 되살리기 | 읽은 것은 모두 글자 — `strip( )` · `int( )` / 껐다 켜도 펫이 돌아온다 |
| 6 | 🧺 저장했는데 빈 파일? | 바구니(버퍼) — 닫기 전에는 디스크에 없다 → `with` |
| 7 | 🆕 처음 온 친구 | 세이브가 없으면 `FileNotFoundError` → `try–except` |
| 8 | 💾 세이브는 `'w'` | `'a'` 로 저장하면 불러올 때 옛날 레벨이 나온다 |
| 9 | 📜 일지는 `'a'` | `'w'` 면 마지막 하나만 남는다 · `for line in f` · 모드 고르기 |
| 10 | ⭐ 세이브 조작 | 파일은 그냥 글자(레벨 99!) · 깨진 세이브 |
| 11 | 🏆 끝판왕 | 저장 · 불러오기 · 일지를 끼워 자동 검사 7가지 |
| 12 | ✅ 확인 문제 · 오늘 배운 것 | 교재 확인 문제 꼴 6문항 + 내 말로 정리 |

## 수업 운영 도움말

- **50분 배분(예)** — 0~1 도입 5분 · 2~5 저장과 불러오기 15분 · 6~9 15분 · 11 끝판왕 10분 · 12 정리 5분.
- 화면은 1280×720 「무대」 한 장이라 교실 TV·전자칠판에서도 스크롤 없이 그대로 커집니다.
- **새로 고침 = 프로그램을 껐다 켠 것**입니다. 펫(메모리)은 사라지고 가상 디스크의 파일만 남습니다.
  5번 카드에서 불러오기 코드를 끼운 학생은 새로 고침해도 펫이 돌아옵니다 — 수업 내용 그대로예요.
- 채점은 코드 글자가 아니라 **실행 결과**(화면 출력 · 실행 뒤 남은 파일 · 남은 변수)로 하고,
  늘 「다른 펫」 으로 한 번 더 돌려 봅니다. `'비트'` 를 글자 그대로 적은 답은 통과하지 못합니다.
- 오류가 나면 진짜 파이썬과 같은 Traceback 아래에 한국어 풀이가 붙습니다. 힌트는 누를 때마다 하나씩 열립니다.

## 개발

```bash
npm install
npm start            # 개발 서버 (index.html)
npm test             # 진짜 파이썬 대조 · 미션 채점 · 확인 문제 정답
npm run check:syntax # 소스 전수 검사
npm run build        # dist/index.html 한 파일 + 빌드 점검
npm run golden       # 진짜 파이썬 3.12 로 대조 기준 다시 만들기 (파이썬 필요)
```
